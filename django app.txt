This command activates your Python virtual environment.
source .venv/bin/activate


What each part means:
Part	Meaning
source	Runs a script in your current shell so its environment changes apply to that shell.
.venv/	The directory containing your Python virtual environment.
bin/activate	The script that activates the environment.



This command starts your Django application.
python manage.py runserver 0.0.0.0:8000


Let's break it down:
Part	Meaning
python	Runs Python from the active environment.
manage.py	Django's project management script.
runserver	Starts Django's built-in development web server.
0.0.0.0	Makes the server listen on all available IPv4 network interfaces.
8000	The TCP port on which Django listens.
