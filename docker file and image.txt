Have a source code form the github

Create a docker file to create the IMAGE:

FROM ubuntu:latest # this will fetch the base OS from docker hub public registry

WORKDIR /app # DIR where the source file will be and image will Create

COPY requirements.txt /app/
COPY app.py /app/ #copy the soure code and move to app dir

RUN apt-get update && apt-get install -y python3 python3-pip python3-venv # installing dependencies

SHELL ["/bin/bash", "-c"]

RUN python3 -m venv venv1 && \
source venv1/bin/activate && \
pip install --no-cache-dir -r requirements.txt

EXPOSE 8000

CMD source venv1/bin/activate && python3 manage.py runserver 0.0.0.0:8000

Example:

FROM ubuntu:latest # this will fetch the base OS from docker hub public registry

WORKDIR /app # creates /app inside the image if necessary and sets it as the working directory.

COPY requirements.txt /app/
COPY app.py /app/ #copy the soure code and move to app dir

RUN apt-get update && apt-get install -y python3 python3-pip python3-venv # installing dependencies

CMD ["python3" , "app.py" ] #command to start the application

IMAGE CREATION:

Now docker file is ready now build image from it.

use cmnd:

docker build -t username of dockerhub/imagename:latest . #dot is represent docker file is in same dir

#or if docker file is in diff dir use -f /home/dockerfilename

docker build -t pranesh/webapp:latest -f Dockerfile .


What each part means
Part	Meaning
docker build	Builds a Docker image
-t	Assigns a name and tag to the image
pranesh/webapp	Image name, using your Docker Hub username
:latest	Image tag
-f Dockerfile	Specifies the Dockerfile to use
.	Build context — the current directory whose files Docker can access during the build

Important: The final . is required in this example. It tells Docker to use the current directory as the build context.
 

Dockerimage -- to list  the image present
